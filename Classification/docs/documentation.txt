
PROJECT DOCUMENTATION
PHISHING WEBSITE DETECTION USING MACHINE LEARNING AND DEEP LEARNING

1. INTRODUCTION

Phishing is a type of cyberattack in which attackers create deceptive websites to steal sensitive information such as usernames, passwords, banking details and personal data.

Phishing websites are designed to appear similar to legitimate websites. Detecting these websites manually can be difficult. Machine Learning and Deep Learning techniques can help identify suspicious website patterns and classify websites automatically.

This project develops a phishing website detection system using Machine Learning and an Artificial Neural Network.

2. OBJECTIVES

The main objectives of this project are:

- To understand phishing website detection.
- To analyze and prepare a phishing website dataset.
- To implement a Random Forest classification model.
- To improve model performance using hyperparameter tuning.
- To develop an Artificial Neural Network model.
- To compare Machine Learning and Deep Learning performance.
- To evaluate the models using classification metrics.

3. DATASET DESCRIPTION

The project uses the Phishing_Legitimate_full.csv dataset.

Dataset details:
- Total records: 10,000
- Total columns: 50
- Input features used: 48
- Target column: CLASS_LABEL
- ID column: id

The ID column is excluded from model training because it is an identifier rather than a predictive feature.

The target column contains two encoded classes: 0 and 1.

The dataset contains 5,000 records in each class, making the dataset balanced.

5. METHODOLOGY

The project follows these steps:

1. Dataset collection
2. Dataset inspection
3. Data preprocessing
4. Feature preparation 
5. Training and testing data splitting
6. Machine Learning model development
7. Hyperparameter tuning
8. Deep Learning model development

The dataset is divided into 80% training data and 20% testing data using stratified splitting.

6. DATA PREPROCESSING

The dataset was inspected for missing values and duplicate records. No missing values or duplicate records were found. The ID and target columns were separated from the input features.

A total of 48 numerical features were used for model training. The dataset was divided into training and testing sets using stratified splitting while maintaining the original class distribution.

For the Artificial Neural Network, StandardScaler was used to scale the input features. The scaler was fitted only on the training data and then applied to the testing data.

7. MACHINE LEARNING MODELS

7.1 Random Forest Classifier

Random Forest is an ensemble learning algorithm that combines multiple decision trees to perform classification.

Each decision tree makes a prediction, and the final output is determined through majority voting.

The implemented model uses 200 decision trees.

7.2 Improved Random Forest Classifier

GridSearchCV is used to find suitable hyperparameters for the Random Forest model.

Five-fold cross-validation is used during the tuning process.

The selected parameters are:

- Number of estimators: 200
- Maximum depth: None
- Minimum samples split: 2
- Minimum samples leaf: 1
- Maximum features: sqrt

The GridSearchCV process selected the same effective configuration as the baseline Random Forest model. Therefore, both models achieved identical performance on the testing dataset.

The tuned model is evaluated using the same testing dataset.

8. DEEP LEARNING MODEL

8.1 Artificial Neural Network (ANN)

An Artificial Neural Network is a Deep Learning model inspired by the structure of the human brain.

The implemented ANN contains:

- Input layer: 48 features
- Hidden layer 1: 128 neurons with ReLU activation
- Dropout layer: 0.2
- Hidden layer 2: 64 neurons with ReLU activation
- Dropout layer: 0.2
- Hidden layer 3: 32 neurons with ReLU activation
- Output layer: 1 neuron with Sigmoid activation

The model uses:
- Optimizer: Adam
- Loss function: Binary Crossentropy
- Evaluation metric: Accuracy
- Batch size: 32
- Maximum epochs: 100

EarlyStopping is used to stop training when validation loss stops improving and to restore the best model weights.

9. MODEL EVALUATION

The models are evaluated using the following performance metrics:

Accuracy:
Measures the proportion of correctly classified predictions.

Precision:
Measures how many predicted positive cases are actually positive.

Recall:
Measures how many actual positive cases are correctly identified.

F1 Score:
Represents the harmonic mean of precision and recall.

A confusion matrix is also generated to visualize correct and incorrect predictions.

10. PERFORMANCE COMPARISON

The obtained test results are:

Model	                Accuracy	Precision	Recall	 F1 Score
Random Forest	         98.50%	     98.89%	    98.10%	  98.49%
Improved Random Forest	 98.50%	     98.89%	    98.10%	  98.49%
ANN	                     97.70%	     97.51%	    97.90%	  97.70%

Both Random Forest models correctly classified 1,970 out of 2,000 testing records, while the ANN correctly classified 1,954 records.

The Random Forest and Improved Random Forest models achieved the same test performance.

The Artificial Neural Network achieved an accuracy of 97.70%.

Based on the obtained results, Random Forest achieved the highest performance across all four evaluation metrics.

11. RESULTS AND DISCUSSION

The experimental results show that the Random Forest classifier performs well on the selected dataset.

Hyperparameter tuning selected the same configuration as the original Random Forest model. Therefore, both models produced identical test results.

The Artificial Neural Network also achieved good classification performance, but its results were slightly lower than those of Random Forest.

This experiment demonstrates that a Deep Learning model does not necessarily outperform a traditional Machine Learning model on every dataset.
